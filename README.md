## 🚀 Local Development

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Local Development Server**:
   ```bash
   npm run dev
   ```

3. **Build Production Bundle**:
   ```bash
   npm run build
   ```

## 🌐 Deploying to Vercel (Recommended #1 Free Option)

1. Push your code to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Executive Portfolio Website"
   git branch -M main
   git remote add origin https://github.com/Rinub/portfolio_website.git
   git push -u origin main
   ```

2. Go to **[vercel.com](https://vercel.com)** and sign in with GitHub.
3. Click **"Add New Project"** and select **`Rinub/portfolio_website`**.
4. Vercel will automatically detect Vite + React. Click **"Deploy"**.
5. Your portfolio is live instantly with free SSL, global CDN, and automated updates on every `git push`!
